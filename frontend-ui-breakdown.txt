# Nexara Food — Current Frontend UI/UX Breakdown

## Design System

```
Primary color:  #dc2626 (red)
Background:     #fafaf9 (warm white)
Surface:        #ffffff (white cards)
Text:           #1c1917 (near black)
Text secondary: #57534e (warm gray)
Border:         #e7e5e4 (light gray)
Font:           system-ui stack
Max width:      960px
Border radius:  12px (cards), 8px (inputs)
Header height:  64px, sticky
```

```
┌─────────────────────────────────────────────┐
│ [Header: Nexara logo | EN ▼ | Login | Reg]  │
├─────────────────────────────────────────────┤
│                                             │
│     Nexara — Food Delivery (h1, 28px)        │
│   Order from the best restaurants (15px)    │
│   ┌──────────────────────────────┐          │
│   │ Search restaurants...        │          │
│   └──────────────────────────────┘          │
│                                             │

│  │ [image]  │  │ [image]  │  │ [image]  │  │
│  │ Name     │  │ Name     │  │ Name     │  │
│  │ Desc...  │  │ Desc...  │  │ Desc...  │  │
│  └──────────┘  └──────────┘  └──────────┘  │
│                                             │
└─────────────────────────────────────────────┘
```

- Hero section: centered title + subtitle + search input (480px max-width)
- Restaurant cards: 260px min-width grid, image (160px height, cover), name + 2-line description
- Cards have hover lift effect (translateY -2px)
- No categories, no filters, no delivery time, no rating, no "open/closed" badge
- Mobile: single column, smaller title

│ └───────────────────────────────────────┘   │

│ ┌── Menu (left) ──┐ ┌── Basket (right) ──┐  │
│ │                 │ │                    │  │
│ │ [img] Name      │ │ Basket (sticky)    │  │
│ │       Desc      │ │                    │  │
│ │       $price  [+]│ │ Item × qty  $price │  │
│ │                 │ │ [-][1][+][✕]       │  │

```

- Two-column layout: menu (flexible) + sidebar (360px, sticky)
- Food items: horizontal row — 64px image, name + desc + price, red circle "+" button
- Basket: sticky sidebar, item list with qty controls (-/+/✕), subtotal/delivery/total
- "Place Order" button shows item count
- Clicking it reveals inline form: address, phone, note, confirm/cancel
- No food categories/tabs, no search within menu, no "popular" section
- Mobile: single column, sidebar becomes static below menu

```

- Sticky, white background, bottom border
- Logo: "Nexara" in red, 18px, bold
- Language switcher: small select with flag emojis (TJ/RU/EN)
- Role-based nav links
- No cart icon with count, no mobile hamburger menu, no search in header
- On mobile: logo shrinks, username hidden

## What's Missing (Compared to Modern Food Delivery Apps)

```
  · Bottom navigation bar (mobile)
  · Category tabs on homepage
  · Food category tabs inside restaurant menu
  · Delivery time estimates
  · Restaurant rating/stars
  · "Open now" / "Closed" badges
  · Cart floating button with item count
  · Food item modals/popups (instead of inline add)
  · Order tracking map
  · Push notifications
  · Dark mode
  · Skeleton loading states
  · Pull-to-refresh
  · Price in TJS (currently shows $)
  · Restaurant logo (currently full-width banner)
  · Food item cards with better layout (image left, details right)
  · Quantity selector on food items before adding
  · "Popular items" section
  · Search within restaurant menu
  · Order history with dates
  · Reorder functionality
  · Admin dashboard with stats (orders today, revenue, etc.)
  · Admin order detail view
  · Courier "mark delivered" button
  · Courier navigation/directions
```
